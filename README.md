# 🎬 React Movie App

**Movie Mania** is a simple and visually appealing web application that allows users to browse popular movies using an external API. Built using React JS, the app features movie cards, dynamic routing, and a responsive design.

---

## 🚀 Features

- 🎞️ Fetch and display trending/popular movies
- 🔍 Search functionality 
- 🖼️ Movie posters, titles, release year
- ⚡ Fast, responsive UI built with React
- 🌐 Fetches real-time data using an external movie API (like OMDb)

---

## 🧰 Tech Stack

- React JS
- HTML5 & CSS3
- JavaScript
- Axios / Fetch API
